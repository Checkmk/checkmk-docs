== SAML-Verbindungen zu bestimmten Instanzen zuweisen

// ES-todo (CMK-34062)
////
SAML on distributed sites
* Admins assign a SAML connector to a remote site via Setup > Distributed Monitoring > [site] > Authentication connections.
* Two modes: pick an explicit list of connectors, or inherit from the central site's assignment. A remote site can use SAML without the central site using it.
* The assignment persists across central config pushes — it is not overwritten.
* Sessions are site-scoped: a session on a remote site does not affect other sites.
* New users logging in via SAML on a remote site for the first time are automatically created with default attributes.
