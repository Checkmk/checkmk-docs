== Host mit Agent erstellen

Im Folgenen wird die Erstellung eines Hosts mit Agent beschrieben. Voraussetzung an diesem Punkt ist eine laufende Checkmk-Instanz mit Zugriff auf die Weboberfläche. Die nachfolgende Beschreibung richtet sich an Personen, die bereits mit den Grundbegriffen xref:glossar#host[Host], xref:glossar#service[Service] und xref:glossar#agent[Agent] vertraut sind.

[.tabs]
====
[#tab_windows]#Linux#::
+
--
So überwachen Sie einen Linux-Host mit dem Checkmk-Agenten.

*Voraussetzungen*

* Der Ziel-Host ist per Netzwerk erreichbar, sein Name ist idealerweise per DNS auflösbar.
* Sie verfügen über `root`- oder `sudo`-Rechte auf dem Ziel-Host.
* Der Ziel-Host läuft mit systemd (Standard seit 2015 in den meisten Distributionen).
  Ist das nicht der Fall, verwenden Sie stattdessen xref:agent_linux_legacy#[Linux überwachen im Legacy-Modus].

*Host anlegen*

Öffnen Sie Setup > Hosts > Hosts und wählen Sie den Zielordner (z. B. Linux).
Klicken Sie [.guihint]#Add host# und tragen Sie unter [.guihint]#Host name# den gewünschten Namen ein.

* Ist der Name nicht per DNS auflösbar, tragen Sie die Adresse manuell im Feld [.guihint]#IPv4 address# ein. 
* Wird der Host ausschließlich über einen Spezialagenten abgefragt, setzen Sie [.guihint]#IP address family# auf [.guihint]#No IP#.

Speichern Sie mit [.guihint]#Save host & next step#.

*Agenten herunterladen und installieren*

Klicken Sie [.guihint]#Test agent connection#.
Wählen Sie nach dem erwarteten Fehlschlag [.guihint]#Download Checkmk agent#.
Wählen Sie im Slideout das Betriebssystem Linux sowie das passende Paketformat:

* DEB für Debian und Ubuntu 
* RPM für Red Hat Enterprise Linux (RHEL), binärkompatible Distributionen und SUSE Linux Enterprise Server (SLES)

Klicken Sie [.guihint]#Generate one-time token#, kopieren Sie den angezeigten Befehl und führen Sie ihn auf dem Ziel-Host in einem Terminal aus. Geben Sie bei Aufforderung Ihr sudo-Passwort ein.

*Host registrieren*

Klicken Sie im Slideout [.guihint]#Next step: Register agent# und anschließend [.guihint]#Generate one-time token#.
Kopieren Sie den angezeigten Befehl (er nutzt `cmk-agent-ctl` mit der Option `-ott) und führen Sie ihn auf dem Ziel-Host aus.
Bestätigen Sie das angezeigte Server-Zertifikat mit 'Y'.
Schließen Sie mit [.guihint]#Close & test connection# ab.
Die Verbindung ist jetzt TLS-verschlüsselt.

*Services konfigurieren*

Klicken Sie auf der Seite [.guihint]#Properties of host# auf [.guihint]#Save & run service discovery#.
Übernehmen Sie die gefundenen Services mit [.guihint]#Accept all#, oder wählen Sie gezielt einzelne Services über die Kategorien [.guihint]#Undecided#, [.guihint]#Monitored#, [.guihint]#Disabled# und [.guihint]#Vanished# aus.

*Änderungen aktivieren*

Öffnen Sie das Menü [.guihint]#Changes# in der Navigationsleiste und klicken Sie [.guihint]#Activate pending changes#.
Prüfen Sie das Ergebnis über [.guihint]#Monitor > Overview > Main dashboard#.

Wenn die Agentenverbindung fehlschlägt: Nutzen Sie die Diagnosemöglichkeiten im Artikel xref:monitoring_agents#[Monitoring-Agenten] sowie die Test- und Diagnosefunktionen im Artikel xref:monitoring_linux#[Linux überwachen].

Referenz: Übersicht der Host-Attribute in Kapitel 6.1 der xref:hosts_setup#[Verwaltung der Hosts.]

[#tab_windows]#Windows#::
+
--
So überwachen Sie einen Windows-Host mit dem Checkmk-Agenten.

Voraussetzungen
    • Der Ziel-Host ist per Netzwerk erreichbar, sein Name ist idealerweise per DNS auflösbar. 
    • Sie verfügen über Administratorrechte auf dem Ziel-Host, um das MSI-Paket zu installieren. 
1. Host anlegen
Öffnen Sie Setup > Hosts > Hosts und wählen Sie den Zielordner (z. B. Windows). Klicken Sie Add host und tragen Sie unter Host name den gewünschten Namen ein.
    • Ist der Name nicht per DNS auflösbar, tragen Sie die Adresse manuell im Feld IPv4 address ein. 
Sichern Sie mit Save host & next step.
2. Agenten herunterladen und installieren
Klicken Sie Test agent connection. Wählen Sie nach dem erwarteten Fehlschlag Download Checkmk agent. Wählen Sie im Slideout das Betriebssystem Windows; Checkmk bietet das Paket als MSI-Installer an.
Klicken Sie Generate one-time token, kopieren Sie den angezeigten Befehl und führen Sie ihn auf dem Ziel-Host in einer PowerShell mit administrativen Rechten aus.
3. Host registrieren
Klicken Sie im Slideout Next step: Register agent und anschließend Generate one-time token. Kopieren Sie den angezeigten Befehl (er nutzt cmk-agent-ctl mit der Option -ott) und führen Sie ihn auf dem Ziel-Host aus. Bestätigen Sie das angezeigte Server-Zertifikat mit Y.
Schließen Sie mit Close & test connection ab. Die Verbindung ist jetzt TLS-verschlüsselt.
4. Services konfigurieren
Klicken Sie auf der Seite Properties of host auf Save & run service discovery. Übernehmen Sie die gefundenen Services mit Accept all, oder wählen Sie gezielt einzelne Services über die Kategorien Undecided, Monitored, Disabled und Vanished aus. Beachten Sie, dass Windows-Hosts andere Services liefern als Linux-Hosts.
5. Änderungen aktivieren
Öffnen Sie das Menü Changes in der Navigationsleiste und klicken Sie Activate pending changes.
Prüfen Sie das Ergebnis über Monitor > Overview > Main dashboard.
Wenn die Agentenverbindung fehlschlägt: Nutzen Sie die Diagnosemöglichkeiten im Artikel Monitoring-Agenten.
Referenz: Details zu den unter Windows verfügbaren Services siehe Windows überwachen.
