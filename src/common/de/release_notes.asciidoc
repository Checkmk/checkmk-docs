== OS für den Server

{CMK} kann auf den folgenden Linux-Server-Betriebssystemdistributionen und -versionen installiert werden, die auf x86_64-Hardware laufen.
Um eine grobe Abschätzung der Hardwareanforderungen zu erhalten, besuchen Sie link:https://checkmk.com/product/checkmk-system-requirements[die gleichnamige Seite innerhalb der {CMK}-Website^].

* Mit _deprecated_ gekennzeichnete LTS/LTSS-Versionen werden noch während des gesamten Produkt-Lifecycles von Version {current-major} unterstützt und fallen danach aus dem Support heraus.

[#agent_linux]
=== Linux/Unix

Alle Linux-Distributionen und diverse Unix-Betriebssysteme wie _Solaris_ und _AIX_ werden unterstützt, sofern sie mindestens die folgenden technischen Komponenten in der minimalen Version mitbringen:

* Bash >= 4.2 (Linux, Solaris)
* ksh >= 93 (nur AIX)
* Python >= 3.6 (optional für Agentenplugins)
* Perl >= 5.14.0 (optional für Agentenplugins)

Zusätzlich muss eine der folgenden Komponenten vorhanden sein:

* systemd >= 219
* xinetd (keine Mindestversion)

Beachten Sie: Es kann sein, dass Plugins für ihre Funktion zusätzliche Komponenten benötigen.
// Python-Plugins erfordern Version >= 3.6.
// Python 2.7 wird nicht mehr unterstützt.

[#agent_updater]
==== Automatische Agenten-Updates

Für Linux auf `x86_64` mit _glibc_ 2.17 oder höher stehen Binärpakete des xref:agent_deployment#[Update-Plugins] zur Verfügung.
Für andere Plattformen oder andere Unix-Systeme wird dieses als Python-Skript (erfordert Python >= 3.7) bereitgestellt.
endif::[]

ifdef::saas[]
[#agent_linux]

Eine _Software Bill of Materials (SBOM)_ ist nach der Installation von {CMK} unter `~/share/doc/bill-of-materials.json` und `~/share/doc/bill-of-materials.csv` verfügbar.
Das Format der JSON-Datei ist _CycloneDX_.
Die Version der zugrunde liegenden CycloneDX-Spezifikation entnehmen Sie bitte der jeweiligen JSON-Datei.

Falls Sie die SBOM vor Download und Installation überprüfen wollen, finden Sie im Download-Verzeichnis von {CMK} je eine JSON- und eine CSV-Datei plus die dazugehörigen Hash-Dateien.
Für die aktuelle Version {current} stehen die folgenden SBOM-Dateien bereit:
